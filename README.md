# FiestaApp

Aplicación móvil para productores de fiestas: gestión de eventos, preventas de entradas, vendedores RRPP, ubicación en mapa y pronóstico del clima. Versión móvil de [FiestaWeb](https://github.com/fabripprog/FiestaWeb).

## Instalación

Copiá `.env.example` a `.env` y completá las variables con tus credenciales de Firebase.
